14

Usage Rules

Critical guidelines for maintaining design system consistency.
01
Primary text WCAG
Use --primary-text (oklch 0.45) for green text on light bg. --primary (oklch 0.76) is for backgrounds only — fails AA as text on white.
02
Success = Teal
Success uses hue 190 (teal), not primary green hue 148. Prevents badge/toast collision with primary.
03
Selection indicator
Selected: bg-accent text-accent-foreground (no border). Unselected: hover:bg-muted/50. Background-based, not border-based.
04
Badge shape
rounded-md (not rounded-full). Badges use border + text color, not filled bg.
05
Font weight rendering
Manrope renders lighter than Inter. Body uses font-medium (500). ExtraBold (800) for hero H1 only.
06
Warning foreground
Dark text on orange. White on orange-500 fails WCAG AA.
07
Focus ring
ring-1 ring-ring (1px green) — consistent width, color, offset across all interactive elements.
08
Border-based depth
Minimal shadows. Prefer border-based depth per baseten geometric aesthetic.
09
Chart accessibility
Staggered luminance across chart colors for colorblind distinguishability. Hues spread across wheel.
10
CSS var chain
Use --font-sans-fallback in @theme, never --font-sans.
